茸平路19号 · 绿色用能规划提案

01决策摘要

本页要点　零出资，仅做三件事（引荐业主 / 指定对接人 / 场地协调），贵司年得 10–25 万运营服务费，并稳固招商基本盘。
决策层先读这 4 行：
您得到① 运营服务费 10–25 万 / 年（零出资）；② 租户电费降 10–15% → 续租率与出租率提升 → 管理费基本盘更稳；③ 零碳品牌 + 政策入口。
您做啥仅三件事：引荐业主、指定 1 名对接人、场地协调。勘测 / 施工 / 运维 / 售电 / 结算全由晶科负责。
有风险吗业主授权前：零出资、零义务。授权后：仅签轻资产服务协议，不背资本、不兜底、可提前终止。
下一步先签零义务《合作意向》锁定贵司独家运营方身份 → 再引荐业主、授权晶科免费勘测（勘测不构成任何合同义务）。

一笔算得清的账：服务费 10–25 万 / 年，若随项目全程运行（测算约 25 年），贵司累计服务收益可达 250–625 万元——零出资、零风险。引荐业主不是"惹事"，而是给业主送一笔白来的屋顶租金，您是中间递话、顺手成事的人，不背任何义务。为何是晶科：组件自供 + 自有资本，度电成本与交付更优，且光伏 / 售电 / 充电 / 零碳一次打包，贵司只需一个接口。
现金只是其中一层：服务费（10–25 万 / 年）是显性回报；更关键的是隐性回报——电费下降抬升续租率与出租率，稳住管理费基本盘；零碳品牌强化招商话语权与政策入口。对一家以运营园区为业的公司，后者价值高于前者。
唯一前置条件：项目以业主屋顶授权为前提。晶科提供授权路径与法律安全背书，贵司角色为"引荐 + 协调"，业主未确认前无任何出资或履约义务。
